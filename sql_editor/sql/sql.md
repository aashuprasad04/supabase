1. CREATE
```sql
  CREATE TABLE public.emp(
    id bigint generated by default as identity primary key,
    name varchar(100),
    age int,
    salary numeric(10,2) 
  );
```
2. INSERT INTO
```sql
  insert into public.emp(name,age,salary)
  values
  ('RAHUL', 22, 15000),
  ('RAVI',25,20000)
```
